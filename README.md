# Rock Paper Scissors Game (Python + Tkinter)

## Project Description

This repository contains a graphical Rock Paper Scissors game built using Python and Tkinter.

The application allows the user to play Rock Paper Scissors against the computer. The player selects rock, paper, or scissors using buttons, while the computer randomly chooses its move.

The program displays images for both the player's choice and the computer's choice. The score and remaining lives are tracked throughout the game.

This project demonstrates how Python can be used to create interactive graphical games using event-driven programming and randomization.

---

## Technologies

* Python
* Tkinter
* Random module

---

## Projects Included

### Rock Paper Scissors Game

File: `main.py`

This project implements a graphical Rock Paper Scissors game where the player competes against a computer opponent.

Features include:

* graphical user interface using Tkinter
* buttons for player choices (rock, paper, scissors)
* random computer move generation
* visual display of game choices using images
* score tracking
* life counter system
* game over message when lives reach zero

The computer randomly selects its move, and the program compares the player's choice with the computer's choice to determine the result.

---

## How to Run

Run the program:

```
python main.py
```

Make sure the following image files are in the project folder:

* rock.png
* paper.png
* scissors.png

## Purpose of the Repository

This project was created to practice building graphical games using Python and Tkinter.
